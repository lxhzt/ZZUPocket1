## 已落地的边界

- 保留原金融功能代码，但阻断资金相关网络连接与令牌交换入口。
- 收紧学校网络请求范围、凭据保存、WebView、备份和会话分区。
- 保留仅用于本地虚构输入的 Android 离线实验变体，实验包与测试包均移除 INTERNET 权限。
- 保存公开资料调查与证据摘要；没有执行学校资金操作、登录态令牌交换或学校压力测试。
