# 离线 Android 运行验证计划

日期：2026-10-28。继续既有安全目标；本阶段补充 Android 运行证据，不替代学校权限证明或真实用户登录回归。

## 安全边界与先决条件

- 实验包使用独立 `securityLab` 变体、独立应用标识与私有数据；测试包也显式移除 `INTERNET` 权限，编译产物与运行时均检查权限被拒绝。未通过时不得运行页面测试。
- 测试 Application 不启动业务调度；使用虚构 Cookie、账号标记与课表，所有客户端配置拒绝 DNS/终端假传输。学校页面不下载、不执行；内联 HTML 仅用于本地 WebStorage 验证。
- 测试真实生产 GMS Dialog 时，先确认 WebView 默认阻止网络加载。此变体不改变正式应用的联网权限或业务协议。
- 模拟器和镜像仅使用 Android 官方来源，核对实际官方元数据中的校验算法和值。安装范围限工作区 SDK/AVD，不安装虚拟化驱动、不启用 Windows 特性、不改主机防火墙、不连接任何用户手机。
- 先检查已有加速能力；若只能软件运行，则限制内存/CPU并设定启动超时。不满足条件时保留可审查的测试工具，明确未实际运行，不重复启动或把 JVM 结果冒充 Android 结果。
- 正常工具下载及模拟器系统自身的常规连接不等于实验 App 的联网；本阶段对 App 的“无学校请求”依据是双包没有联网权限及 WebView 阻止网络加载。不得将 DNS/代理参数或飞行模式单独称为完整外网隔离。

## 实验顺序

1. 构建专用实验与测试 APK，核对包名、Application、非导出 HarnessActivity、两包无联网权限；核对正式发布变体未带入实验组件。
2. 在自建虚拟设备中安装专用包，仅通过指定 emulator serial 操作，不接触其他设备。
3. 第一阶段使用真实 TokenStore 写入虚构会话与分区标记，强制停止本实验进程；第二阶段新进程恢复，验证分区和计数器持久化、退出后不复用。
4. 使用内联 HTML 和虚构 Cookie 调用生产 WebSessionCleaner，等待实际 Cookie/WebStorage 清理结果。
5. 渲染生产 GMS Dialog，检查真实 WebView 设置、FLAG_SECURE、窗口属性与合成遮挡触摸拒绝；不提交登录表单。
6. 用真实 Room 内存数据库验证 legacy/A/B 导入课表分区的保留、主键隔离、当前读取、旧快照发布拒绝和退出保留数据。
7. 导出机器可读结果、平台/WebView版本、APK哈希及必要窗口证据；停止模拟器。重新核对正式构建与既有回归，更新同一草稿 PR。

## 解释范围

虚拟设备不代表真实硬件 Keystore；进程冷恢复不证明断电原子性；本地 Cookie 清理不证明学校服务器撤销已盗凭据；合成触摸不代表全部恶意覆盖层/辅助服务攻击。学校授权范围、实际登录兼容性和正式所有者签名仍需另外的证据，不能凭本阶段宣布资金安全保证或完整中等强度安全验收完成。
