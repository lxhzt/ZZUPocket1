# ZZUPocket 0.33.0-launch.1

首个可侧载的安全整改测试版。桌面显示为“ZZUPocket 安全测试版”，适用于 Android 12（API 31）及以上，版本码 90，包名 `com.zzupocket.app.secure`。

## 安装

下载 `ZZUPocket-0.33.0-launch.1.apk`，核对同页 `SHA256SUMS.txt` 后在手机上打开安装。它使用本项目独立发布密钥签名，属于优化后的 release 构建，不是 debug 包。可与原作者应用并存，不自动导入原应用的私有数据。

如果手机上已有同包名且不同签名的开发包，Android 会拒绝覆盖安装；请先自行备份需要的数据，再决定是否移除旧开发包。后续更新必须使用同一签名密钥和更高版本码。

## 当前功能边界

- 校园卡、电费和相关账户网络接口及令牌交换保持关闭，原实现代码保留；历史数据仅供离线查看。
- 图书馆连接和在线接口诊断保持关闭。
- 本科教务及研究生教务沿用既有协议与收紧后的请求范围，未新增学校端口探测。
- 增加凭据保存、备份、网络、WebView、遮挡触摸和会话缓存分区防护。

## 发布定位

此版本供先行安装和功能验证。学校端统一凭据的权限范围及跨系统资金隔离尚未完成登录态验证；也尚未完成真实 Android 设备运行验证。因此不能宣称已保证资金安全，或已通过完整中等强度安全验收，不宜据此直接面向全校推广。

构建、检查结果和 APK/签名证书校验值见同分支 `docs/security-launch-verification-20261028.md` 与 `docs/security-evidence/launch-20261028.json`。签名私钥、密码、学校凭据和本机原始运行日志均不上传。
