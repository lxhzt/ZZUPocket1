# 受限教务授权的进一步核查计划

日期：2026-10-28。承接凭据类型核查，不扩大为认证绕过或资金业务测试。

- 优先核实新发现的学校开放平台正式申请路径；读取官网直接链接的审批表、开发者首页、该页面引用的配置和必要文档。学校公开说明与平台公开静态文件是主要证据，社区实现仅作候选线索。
- 本阶段程序读取总量最多 16 个已审阅公开资源，继续使用精确 URL 白名单、串行 GET、HTTPS/443、默认证书校验、不跟随跳转、不发送 Cookie 或令牌、不执行脚本。每轮最多 8 次，单响应最多 3 MiB、总响应最多 8 MiB，不递归爬取。网页检索工具的索引/页面读取另行说明，不冒称程序请求总数。
- 已遇到集成说明附件的验证码页面；不获取、识别或绕过验证码，也不猜测附件存储地址，不提交注册或申请，不联系学校人员。
- 判断受限授权时分别检查：是否官方支持、谁可申请、是否能逐接口/读写/数据主体授权、凭据能否只存在后端、App 是否仍接触统一密码或全局令牌、能否访问或兑换资金权限、是否覆盖课表和空教室功能。
- 核对 CAS 网页应用会话候选是否只改变客户端保存方式；不因 Cookie 或 service 名称就将其登记为受限授权。
- 输出候选路线对比、可证实与未证实事项、可交给校方审核的最小权限接入需求。没有学校授权契约时，不虚构 scope、clientId 或接口，不以猜测实现替换现有登录。

读取已公开的技术指南后，确认平台按 scope 授权，且一个 scope 可能绑定多个 API。为核实如何申请完整 scope 以及是否有公开教务服务目录，增加读取指南明确链接的 OpenAPI 对接说明与文档目录（目录若返回 302，仅在审阅目的地后读取一次）。本阶段程序资源上限从 16 调整为 18，不改变其他限制，不调用规范中列出的实际接口。

公开目录进一步列出“数据集市”和“数据中心”服务。为避免遗漏可能承载教务数据的正式开放方式，限定再读取这两项的文档页面及其明确引用的规范文件（共至多四个资源），总上限调整为 22；只审查 API 描述、scope 和数据主体限制，不发起数据查询。没有具体教务 scope 时，不把通用数据查询能力视为安全替代。

版本纠正：数据中心先读取了目录中仍列出的 v1 页面，但目录优先列出的主版本是 v3。保留 v1 页面观察，不读取其规范，补读 v3 页面及其规范；总上限因此为 23。不得用 v1 的范围判断当前全部数据能力，完成这两项数据服务规范审查后停止本阶段程序访问。
